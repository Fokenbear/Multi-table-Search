# 产品规格

## 1. 目标

把分散在多个 Excel 工作簿里的料号、型号和报价，变成一个输入框加一张结果列表：
输入料号，立刻看到它出现在哪些文件、哪个工作表、哪一行，以及那一行的全部内容。

软件面向需要在本机快速定位料号的使用者，是一个本地效率工具，不是数据分析工具。

## 2. 运行环境

- 目标系统：Windows 10 1809（build 17763）及以上的 x64
- 办公软件：目标机自行安装 WPS Office（用于打开原始数据）
- 运行时：Python 3.12 + PySide6；安装包由 PyInstaller 打包，目标机不需要 Python
- 存储：SQLite（随 Python 内置）
- 全程离线：不调用任何云端 API，不上传工作簿

## 3. 数据来源

**工作簿数量不设上限。** 数据源页列出所有已索引的工作簿，可以：

- 一次添加一个或多个 `.xlsx`
- 单独替换其中任意一个（保留它在索引中的位置和编号）
- 单独移除
- 同一个文件（内容 SHA-256 相同）不允许重复添加

每个工作簿可以有任意多个工作表，每个工作表可以包含多个独立数据区域：

- 不同工作表使用不同的表头
- 表头不在第一行、合并单元格标题
- 重复表头（多个"供应商"列）
- 没有表头但有数据的列
- 右侧无表头的补充备注
- 稀疏数据、隐藏行列、多个独立区域

不允许假设所有工作表共用一个模板。

## 4. 导入机制

必须安全：

1. 复制到暂存目录，并校验复制前后的 SHA-256 一致、原文件未在复制期间变化
2. 解析工作簿；解析失败不得留下半份索引
3. 校验行来源、单元格坐标、区域编号连续
4. 导入前备份数据库
5. 用单个事务提交新索引
6. 任何一步失败或取消：保留旧索引、旧副本，界面明确提示

原始 Excel 不允许被移动、修改或删除。导入完成后程序只持有自己的只读副本。

v2.0 只支持 `.xlsx`。其他格式必须明确拒绝，不能静默转换。

## 5. 检索规则

用户输入一个料号或关键词：

- 包含匹配，大小写不敏感
- 只去掉首尾空格
- 不自动删除连字符、不替换特殊字符、不做模糊纠错、不做 AI 推测
- 不限定在某一个"型号"列，所有数据列和补充备注都参与匹配
- 匹配单位是**单元格**：同一个数据行里任意单元格包含关键词即命中；相邻单元格不会被拼接
- 同一行多个单元格命中只输出一次，但记录全部命中位置
- 同一个料号出现在不同工作表、不同工作簿时全部返回
- 结果分页展示，`total_count` 是完整命中数

## 6. 输出规则

每条结果包含：

- 原始文件名
- 工作表名称
- 表格标题（存在时）
- Excel 原始行号
- 命中的单元格位置
- 该行的全部表头与数据
- 右侧无表头备注

示例（虚构数据）：

```
文件名称：sample.xlsx
工作表名称：示例供应商A
表格名称：示例供应商A
Excel 原始行号：125
日期：2026-04-13
询货人：示例用户
型号：A-0001
包装量：10000
已成交：无
供应商（H列）：0.13未 25+ 供应商甲
供应商（I列）：无
供应商（J列）：0.14未 25+ 供应商乙
补充信息（N列）：价格有优势
```

约束：

1. 原始表头名称不能改写
2. 同名表头用列字母区分
3. 没有表头的列显示为 `未命名列（N列）`
4. 有表头但当前行无值时显示 `无`
5. 右侧无表头备注作为「补充信息」输出
6. 不拆分、不改写供应商报价单元格里的原始文本
7. 不只输出命中单元格，必须输出完整行
8. 不因为数据重复而丢弃记录

## 7. 表格识别

必须动态识别：工作表名、表格标题、表头行、数据起止行、实际使用列范围、合并单元格范围。

- 有合并标题时优先用标题作为表格名称，否则用工作表名
- 一个工作表里多个独立区域分别识别
- 纵向合并的单元格，其左上角值关联到覆盖的各行
- 右侧合并备注关联到对应数据行
- 不得直接把 `max_row`/`max_column` 当成有效范围（格式设置会虚增）
- 识别不出表头时不能静默跳过：降级为用 Excel 列字母作字段名，并在导入报告中提示

## 8. 公式与显示值

- 优先读 Excel 已有的缓存计算值
- 没有缓存值时保留公式文本并明确标识
- 不执行宏、不自行计算或猜测公式结果
- 日期、数字格式、前导零尽量保留 Excel 原始显示效果

## 9. 界面

两个页面，左侧导航切换。

### 检索

- 关键词输入框（Enter 触发）
- 结果计数、页码、上一页/下一页
- 每条结果是一张卡片：来源、命中位置、完整行、复制本行、打开原始数据
- 没有索引任何工作簿时，显示空状态并给出「去添加工作簿」入口

### 数据源

- 工作簿列表：文件名、大小、工作表数、数据行数、导入时间、状态
- 添加 / 替换 / 移除；导入期间显示进度并可取消
- 移除和替换前必须二次确认
- 空状态直接给出添加入口

不做图表、不做库存预测、不做 AI 问答。

## 10. 快捷打开原始数据

每条结果都保留原始文件路径、工作表名、行号、命中单元格地址。

点击「打开原始数据」：

- 优先使用 WPS COM 打开工作簿、切换工作表、定位到目标单元格
- 必须探测本机 WPS 的自动化 ProgID，不能假设 `Excel.Application` 存在
- COM 失败时：用系统默认程序打开文件，展示准确的定位信息并允许复制
- 明确告知未能自动定位，不能假装成功
- 不得为了定位而修改原始文件

## 11. 性能

- 导入后建立索引，搜索时不重新解析 Excel
- 大文件导入和搜索不能卡住界面，耗时操作全部在后台线程
- 搜索使用逐单元格匹配，允许使用索引或缓存加速，但结果必须与直接包含匹配一致

## 12. 测试与验收

必须覆盖：解析单元测试、检索准确性、多工作簿多工作表、重复表头、合并单元格、
无表头备注、空白字段、多行重复命中、更新失败回滚、取消、WPS 定位、离线运行、
Windows 安装。

验收必须在真实的 Windows 10 + WPS 环境完成；开发机上的成功不算验收通过。
当前状态见 [TEST_REPORT.md](TEST_REPORT.md)。

## 13. 原则

这是一个检索工具，不是数据加工工具。

不修改数据、不加工数据、不解释数据、不丢失数据。原始数据是什么，就忠实展示什么。
准确性优先于界面美观，数据完整性优先于速度优化。
